# 功能需求与验收

## 角色

| 角色       | 权限                                           |
| ---------- | ---------------------------------------------- |
| 学生       | 搜索、提交、查询码查询、查看公开歌单           |
| 策划       | 审核、排期、调序，读取点歌人信息               |
| 技术员     | 下载已排期歌曲、更新播放状态，不读取点歌人信息 |
| 超级管理员 | 全部能力、配置、账号和告警                     |

## 关键约束

- 点歌使用一次性浏览器 PoW；同 IP 每小时最多 5 次，连续失败会冷却。
- 屏蔽词规则命中时服务端拒绝提交。字面规则按 NFKC 规范化匹配；受限正则使用 `regex:` 前缀。
- 播出规则由每周时段模板和指定日期完整覆盖组成；空例外代表停播。
- 排期、撤排和调序使用节目单版本乐观锁；超出日期、日历、时段、数量或时长限制时拒绝写入。
- 审核状态与播放状态分离：播放状态为待下载、已下载、已播放或播放异常。
- 公开歌单只包含日期、时段、序号、播出时间、歌名和歌手。
- 终态点歌在 7 天后匿名化点歌人、查询码和相关文本。
- 下载经过服务器受控代理与本地缓存；浏览器不会得到上游音频 URL。

## 验收

- [ ] 生产空库未设置初始管理员变量时启动失败。
- [ ] 角色越权、CSRF 缺失和过期会话均无法执行写操作。
- [ ] 并发排期版本冲突返回 409，重排不触发顺序唯一索引冲突。
- [ ] 技术员不可查看点歌人，公开接口不可查看音源标识。
- [ ] 单曲与整日下载仅对仍处于排期中的歌曲开放。
- [ ] PoW 重放、摘要篡改和超过每小时额度均被拒绝。
- [ ] `npm run lint`、`npm run build`、`npm test` 和 `npm run test:e2e` 均成功。
