# 后台角色与工作流

后台入口为 `/admin`。账号使用 HttpOnly Cookie 会话；管理端写操作还需要同源 Origin 校验及 CSRF 令牌。

## 角色权限

| 角色         | 权限                                                               |
| ------------ | ------------------------------------------------------------------ |
| `SUPER`      | 全部功能：账户、站点配置、音源、操作日志、点歌记录、告警与播放状态 |
| `PLANNER`    | 审核、排期、撤排、调序，并读取点歌人身份信息                       |
| `TECHNICIAN` | 下载已排期音频、更新播放状态；无法读取点歌人身份信息               |

## 推荐操作顺序

1. **审核**：在“审核管理”确认歌曲内容、时长和点歌信息，拒绝时填写明确原因。
2. **排期**：选择播出日期与时段。写入排期时会校验当日版本，避免多人同时调整导致覆盖。
3. **调序**：在“播出排期”调整歌曲顺序，并确认时段容量和总时长。
4. **下载**：技术员仅下载已排期歌曲；系统会从已配置音源获取音频，并写入本地或 S3 缓存。
5. **回填**：播出后将状态标记为已播放；发生故障时记录异常，便于管理员处理。

## 账户与邮箱

超级管理员可在“账号管理”维护人员账户，也可批量导入。每个后台用户可在“个人”区域查看用户名、显示名称、角色、密码与邮箱绑定状态。

当站点启用“要求绑定邮箱”后，管理员登录后需要先完成邮箱验证才能继续访问后台功能。

## 操作日志

操作日志仅对超级管理员开放，默认保留 90 天。新日志会记录操作人、动作、目标、请求 IP、User-Agent 和时间。经反向代理部署时，须正确设置 `TRUSTED_PROXY_IPS`，才能记录真实客户端 IP。
