# 系统简介

杨村一中校园广播电视台在线点歌系统是一个单体 Nuxt 4 应用，覆盖学生点歌、后台审核排期、技术下载、播出状态和运行审计。

## 适用对象

| 使用者     | 主要工作                                       |
| ---------- | ---------------------------------------------- |
| 学生       | 搜索歌曲、提交点歌、使用查询码查看处理状态     |
| 审核员     | 审核点歌、安排播出日期和时段、调整顺序         |
| 技术员     | 下载已排期歌曲、登记已下载/已播放/异常状态     |
| 超级管理员 | 管理账号、站点设置、音源、告警、审计及历史记录 |

## 核心流程

```text
搜索歌曲 → 填写点歌信息 → 浏览器验证 → 等待审核
                                      ↓
                         审核通过 → 排入播出时段
                                      ↓
                     技术下载 → 播出 → 回填播放状态
```

## 技术组成

- **前端**：Nuxt 4、Vue、Pinia、Tailwind CSS
- **服务端**：Nitro API 与 Node.js
- **数据库**：SQLite + Drizzle ORM
- **音源**：可在后台配置多个外部 Meting API，并按照优先级故障切换
- **部署**：Docker 镜像或标准 Node.js 运行产物

::: tip 数据位置
默认数据库位于 `data/server.sqlite`。服务启动会按文件名顺序运行 `server/migrations/` 中的迁移；生产更新前请先备份数据库。
:::
